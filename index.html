CoDex combines VLM guidance and online simulated learning to let robots autonomously master complex functional object manipulation skills without human demos.

TL;DR

Why care? CoDex learns dexterous grasp–move–actuate skills for functional object manipulation (FOM) without any human demonstrations.

How we do it:

  1. Query the VLM where the tool should be placed (global guidance) and which part to be actuated (local guidance).
  2. A constrained optimiser finds functional grasps that remain stable and satisfy the actuation requirement.
  3. One hour of RL in simulation turns those grasps into a motion primitive policy that transfers directly to a Franka + Leap hand.

What CoDex achieves: On six unseen tools with different internal actuation mechanisms, the policy reaches 90% grasp stability and 60% holistic success.

Why is Functional Object Manipulation challenging?

"Robots can pick and place, but can they use a spray bottle or a glue‑gun?"

The challenge. Functional Object Manipulation (FOM) tasks demand dexterous grasps that let a robot reposition an object and actuate its internal mechanism—often using the same fingers that keep the object stable.

Why it's hard? Success hinges on a tight coupling between high‑level semantic context (which object, where to aim, how to operate it) and low‑level physical dexterity (contact choice, in‑hand force control, collision‑free motion). CoDex bridges that gap by letting a Vision‑Language Model supply the semantics while simulation‑based optimisation and RL supply the dexterity.

CoDex: Learning Compositional Dexterous Functional Manipulation without Demonstrations

Stage 1 — VLM‑Generated Semantic Guidance

We parse a single RGB‑D snapshot and task text through a VLM to segment the scene, reconstruct the tool mesh, and label the Actuation and Function points. Our VLM‑guided Cross‑Entropy Method then proposes goal poses that satisfy both language constraints and simple physics checks.

Stage 2 — VLM‑Guided Policy Training

We generate candidate grasps that remain stable while enabling actuation, then run one hour of RL in ManiSkill3 (2 048 parallel worlds) to refine them into a single motion primitive that completes grasp–move–actuate end‑to‑end.

Stage 3 — Real‑world Execution

The learned primitive transfers directly to a Franka arm with a Leap hand, executing the full pipeline on unseen objects without any additional tuning.
